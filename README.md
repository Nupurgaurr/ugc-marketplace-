# blackcoffee. UGC — Creator Marketplace

Frontend for a three-sided UGC marketplace: home, client (brand) portal, creator portal, and an admin panel. Next.js 14 (App Router) + TypeScript + CSS Modules + GSAP, running entirely on mock data — no backend yet.

```bash
npm install
npm run dev
```
